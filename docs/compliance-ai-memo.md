# AI / 数据合规备忘（非法律意见）

> 供产品、运营与律师复核使用；**不构成法律建议**。

## 1. 产品定位

炫译是 **Windows 本地工具**，聚合用户**自行配置**的第三方机器翻译 API，不托管用户原文、不提供面向公众的生成式对话产品。

| 维度 | 炫译现状 | 备注 |
|------|----------|------|
| 部署形态 | 本机 exe | 非 SaaS |
| 模型/引擎 | 用户选的云 API | 非自研大模型 |
| 用户数据集中存储 | 无运维服务器 | 降低个人信息处理者义务（仍须合规使用第三方） |
| 面向公众在线服务 | 否（工具下载） | 与「向公众提供生成式 AI 服务」边界不同，但商店分发仍需合规材料 |

## 2. 《生成式人工智能服务管理暂行办法》适用边界（备忘）

- **可能较弱适用：** 仅自用、不分发、不对外提供接口。
- **需重点评估：** 通过应用商店或官网**向公众提供**下载，且默认引导使用境内/境外大模型 API 时，是否被认定为「应用商店中的工具类提供者」或需配合上架方资质要求。
- **建议律师确认：**
  1. 是否需在用户协议中增加生成内容标识义务（界面已加「机器翻译，仅供参考」）；
  2. 是否在隐私政策中单独披露「向第三方 AI 服务传输文本」；
  3. 未来若内置默认 API（非用户自备 Key）是否触发算法备案或安全评估。

## 3. 数据出境

- 文本由用户设备**直连**境外 endpoint 时，可能构成数据出境行为；责任主体通常为**用户或其所在单位**，工具方仍建议在 UI 明确提示（已实现：设置 → 翻译接口）。
- **双重检查清单：**
  - [ ] 用户是否为企业员工，是否需走安全评估/标准合同
  - [ ] 第三方 DPA / 数据处理协议是否签署
  - [ ] 是否可选用境内节点（百炼、Azure 中国区等）
  - [ ] 是否开启本地脱敏
  - [ ] 是否关闭不必要的翻译历史

## 4. 软件著作权（P3-04）

对外商业化或商店上架前，建议办理**计算机软件著作权登记**（源代码 + 说明书）。材料清单见 `炫译开发/reports/上架材料清单.md`。

## 5. 待律师复核问题清单

1. 个人开发者 vs 主体公司上架 Microsoft Store 的资质差异  
2. 隐私政策是否需单独 Cookie/设备标识条款（当前不采集广告标识）  
3. 开源 MIT 分发与中文「用户协议」的并存表述  
4. 若增加崩溃上报（Sentry 等）是否构成新的个人信息处理活动
