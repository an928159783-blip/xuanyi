# 悬停翻译说明

## 统一翻译方向（v0.1.2+）

设置 → **翻译方向：自动（英↔中）** 时，以下方式共用同一规则：

- 选中后自动翻译（可开关）
- 热键、复制后翻译
- 悬停（能读到字时）

| 选中/读到的内容 | 译文 |
|-----------------|------|
| 以英文为主 | 简体中文 |
| 以中文为主 | 英文 |

## 与热键/复制的区别

| 方式 | 技术 | 典型可用场景 |
|------|------|----------------|
| 热键、复制后翻译 | UIA 选区 + 剪贴板 | 大多数能选中复制的软件 |
| **悬停翻译** | 鼠标位置 UIA `TextPattern` | 记事本、部分 Office、部分原生控件 |

**能复制选中 ≠ 能悬停翻译。** 复制走选区/剪贴板；悬停只读「光标下的无障碍文本」，许多程序不暴露这层接口。

## 悬停不触发时的常见原因

1. **未开启**：设置 → 热键与悬停 →「启用悬停翻译」。
2. **鼠标未停稳**：默认需在同一词上停留约 0.5–0.8 秒（`hoverDelayMs`）。
3. **正在拖选**：按住左键时悬停暂停；存在**非空选区**时也会暂停（避免与热键抢译）。
4. **刚按过热键**：热键后悬停会暂停约 15 秒。
5. **程序不支持 UIA 文本**：Chrome、VS Code、Cursor、多数 Electron、扫描版 PDF、游戏画面等。
6. **判定非英文**：中英混排段落可能只提取英文片段，过短则不译。
7. **悬停限速/退避**：默认约 2 次/秒；API 429 后短暂静默（无弹窗）。

## 推荐用法

- **悬停不灵**：选中 → 热键，或开启「复制后自动翻译」后 Ctrl+C。
- **不能选中**：等待 v0.2「OCR 悬停 / 截屏翻译」（见 `ROADMAP-ocr-capture.md`）。
