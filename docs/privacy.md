# 炫译 隐私政策

**生效日期：** 2026-05-26  
**适用版本：** 炫译（HoverTranslate）Windows 桌面客户端

本政策说明炫译如何处理您的信息。炫译为**本地运行**的翻译辅助工具，**不运营**用于收集个人数据的中央服务器。

## 1. 我们收集哪些信息

炫译**不会**要求注册账号，也**不会**将您的 API Key、翻译内容或历史记录上传到炫译运营方。

应用可能在您的电脑上处理或保存以下数据：

| 数据类型 | 是否必须 | 存储位置 | 说明 |
|----------|----------|----------|------|
| API Key 与接口配置 | 使用在线翻译时 | `%USERPROFILE%\.hover-translate\config.json` | 仅本机保存 |
| 翻译历史（可选） | 否 | `%USERPROFILE%\.hover-translate\history.db` | 默认关闭，可在设置中清空 |
| 启动与错误日志 | 否 | `%USERPROFILE%\.hover-translate\logs\` | 用于排障；导出诊断包时可选择附带 |
| 待翻译文本 | 每次翻译时 | 内存；可选历史库 | 按您的操作发送 |

## 2. 数据如何被使用

- **翻译请求：** 待翻译文本从本机**直接**发往您在设置中配置的第三方接口（如 Azure、Google、OpenAI 兼容端点等）。炫译不在中间代传或存档原文至自有服务器。
- **脱敏（可选）：** 若开启「自动脱敏」，会在发送前于本机掩码 token、Bearer、邮箱等片段。
- **诊断导出：** 仅在您点击「导出诊断包」时，由您选择保存位置；导出内容对配置中的密钥做脱敏处理。

## 3. 第三方服务

您自行选择并配置的翻译服务商有其独立的隐私政策与计费条款。使用**境外**接口时，文本可能出境，请在设置 → 翻译接口 查看数据说明，并优先选用符合您合规要求的节点。

## 4. 您的权利

您可随时：

- 在设置中关闭历史、清空历史、导出或删除本地数据；
- 删除 `%USERPROFILE%\.hover-translate\` 目录以移除全部本地配置与历史；
- 卸载应用（不自动删除上述目录，需自行删除若需彻底清除）。

## 5. 儿童与敏感信息

炫译面向一般办公与学习场景，不面向 14 周岁以下儿童主动收集信息。请勿将高度敏感个人信息（医疗、金融账户等）用于机器翻译，除非您已评估风险。

## 6. 政策更新

重大变更时我们会在发行说明（`CHANGELOG.md`）或应用内提示。继续使用即表示您阅读并接受更新后的政策。

## 7. 联系我们

安全问题请参阅仓库内 `SECURITY.md`。其他隐私相关问题，请通过您获取本软件时的发布渠道（如 GitHub Issues、邮箱）联系维护者。
